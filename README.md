# Selenium Login Test Automation

This project is a C# Selenium WebDriver automation project created for testing login form functionality. It uses NUnit as the testing framework and ChromeDriver to run browser-based automated tests.

## Features

- Selenium WebDriver browser automation
- NUnit test framework integration
- Chrome browser test execution
- Reusable BaseTest setup and teardown
- Explicit wait using WebDriverWait
- Negative login test case for wrong email input
- Element-not-found timeout validation
- Manual failure test example included as commented code

## Technologies Used

- C#
- Selenium WebDriver
- NUnit Framework
- ChromeDriver
- SeleniumExtras WaitHelpers

## Project Purpose

The purpose of this project is to practice automated web testing using Selenium and NUnit. It demonstrates how to set up a browser test environment, locate web elements, perform input actions, use assertions, and validate failed login scenarios.
